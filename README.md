# 📝 Task Manager

یک اپلیکیشن مدیریت تسک مدرن، سریع و مینیمال برای مدیریت کارهای روزمره با تمرکز روی تجربه کاربری و ساختار ماژولار.

---

## 🚀 Demo

- 🌐 Live Demo: https://your-project-url.com
- 💻 GitHub Repository: https://github.com/rezabanihabib/quera-tasks-manager

---

## ✨ Features

- ✅ افزودن، حذف و مدیریت تسک‌ها
- 🏷️ دسته‌بندی و انتخاب تگ برای هر تسک
- 🌙 حالت دارک / لایت با ذخیره در LocalStorage
- ⚡ رابط کاربری سریع و واکنش‌گرا
- 🧩 ساختار ماژولار برای توسعه راحت‌تر
- 💾 ذخیره داده‌ها در LocalStorage (بدون نیاز به بک‌اند)

---

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- JavaScript (Modular)
- LocalStorage API

## 📦 Installation

برای اجرای پروژه به Node.js نیاز دارید.

```bash
# نصب پکیج‌ها
npm install
```

---

## ▶️ Development

اجرای پروژه در حالت توسعه:

```bash
npm run dev
```

این دستور:

- Tailwind CSS را کامپایل می‌کند

---

## 🏗️ Build

برای گرفتن خروجی نهایی و بهینه:

```bash
npm run build
```

---

## ⚙️ Scripts

```json
"scripts": {
  "dev": "npm run dev:ts & npm run dev:css",
  "build": "tailwindcss -i ./src/app.css -o ./build/app.css --minify"
}
```
